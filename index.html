    一步一步學會使用
    Grok Bot

    Grok Bot 是一個桌面 AI 助手應用程式。你可以建立多個「bot」，每個 bot 都有自己的對話、性格和記憶，還有自己的桌面和瀏覽器替你辦事。不需要懂得寫程式，會打字就可以。

    從階段 0 開始 直接查看常見問題
    ① 按次序學習每個階段都建基於上一個階段，建議依次完成。
    ② 複製指令試用點擊「跟著做」內的「複製」按鈕，把句子貼到與 bot 的對話中即可。
    ③ 勾選「完成」進度會儲存在這部電腦的瀏覽器中，下次回來仍然記得。
    階段 0

    認識 Grok Bot：幾個基本概念

    目標：用五分鐘弄清楚之後經常會見到的幾個名詞。

    🤖 Bot（助手）一個 AI 助手。你可以建立很多個，每個都有自己的名字、性格和專長，例如「新聞 bot」、「比價 bot」。
    💬 對話每個 bot 都有自己的聊天視窗。你像平常說話一樣打字，它就會回覆，也可以傳送圖片、檔案，或錄製語音訊息給你。
    🧠 記憶你請它記住的事情（例如你住在哪裡、喜歡甚麼），它在之後的對話中都會記得。
    🖥️ 電腦所有 bot 共用一部 Linux 電腦（檔案彼此都看得到），但每個 bot 都有自己的桌面和瀏覽器，你可以隨時查看它正在做甚麼。
    ⏰ 定時任務（Routine）已儲存的任務，會定時自動執行（例如每天早上 8 時），或在某件事發生時觸發。
    📘 技能（Skill）把一套做過的步驟儲存成「食譜」，下次一句話就能照著做。
    🔌 連接器（Connector）連接外部服務，例如 GitHub、X，讓 bot 可以使用你授權的帳戶辦事。
    👥 團隊Bot 之間可以互相傳送訊息、在群組中合作，像一隊同事一樣分工。
    跟著做

    打開 Grok Bot，選擇任何一個 bot，在對話框貼上：

    你請用三句簡單的話，說明你可以幫我做些甚麼。
    預期結果：bot 會用幾句話介紹自己，例如替你搜尋資料、撰寫文字、定時提醒你做事等。
    階段 1

    建立第一個 bot，和它對話

    目標：擁有一個屬於你的 bot，設定好名字和介紹，然後請它完成兩件小事。

    步驟

    1. 在 Grok Bot 中新增一個 bot（如果應用程式中已經有一個 bot，直接使用也可以）。
    2. 點擊對話頂部的 bot 名稱（或按 Cmd+Shift+I），會打開這個 bot 的資料面板。
    3. 點擊面板右上角「X」旁邊的 齒輪，就可以修改它的頭像、名稱、職銜和描述。例如名稱設為「Nancy」，職銜設為「新聞助手」。完成後點擊「X」關閉面板。
    4. 回到對話框，像和朋友傳訊息一樣打字。說得越具體，答案就越切合你的需要。
    跟著做

    例子 A：查詢天氣

    你請幫我查詢香港今天的天氣，用三點說明，最後告訴我外出是否需要帶傘。

    例子 B：撰寫一段介紹

    你請幫我寫一段約 100 字的自我介紹，用於公司內部群組。我叫阿明，從事市場推廣工作，喜歡遠足和攝影，語氣輕鬆一點。

    例子 C（進階）：不同形式的回覆

    你請把剛才那段自我介紹錄製成語音訊息給我聽。
    預期結果：A 會得到一段簡短的天氣摘要；B 會得到一段可以直接使用的文字；C 會收到一段語音訊息。不滿意？直接告訴它「短一點」、「正式一點」即可。

    小技巧：想 bot 以某種語氣或身份做事，也可以直接在對話中說明，例如「你是我的新聞助手，回答時要簡潔」。

    階段 2

    讓 bot 記住你

    目標：請 bot 記住你的喜好，之後不必每次重新說明。

    步驟

    1. 用「請記住……」開頭，說出你想它記住的事情。
    2. 過一段時間（或第二天），問一個需要用到這些資料的問題，看看它是否記得。
    3. 資料有變？直接請它更新或忘記。
    跟著做

    第 1 步：告訴它你的資料

    你請記住：我住在沙田，吃素，平日早上 7 時半起床，希望你用繁體中文回覆我。

    第 2 步：測試它是否記得

    你今晚想出去吃飯，有甚麼推介？

    第 3 步：更新記憶

    你更新一下：我已搬到將軍澳，不再住在沙田了。
    預期結果：第 2 步的推介應該是沙田附近、以素食為主，並且用繁體中文回答你。完成第 3 步之後，它會改為推介將軍澳的選擇。

    注意：不要請 bot 記住密碼、信用卡號碼等敏感資料。

    階段 3

    定時任務（Routine）：每天早上自動發送新聞

    目標：設定一個每天自動執行的任務，不必你開口也會完成。

    步驟

    1. 在對話中使用「每天」、「每天早上」、「提醒我」、「幫我留意」這類字眼，說清楚甚麼時候和做甚麼。
    2. bot 會為你建立 routine，有時會彈出一張確認卡，看清楚內容後再確認。
    3. 點擊對話頂部的 bot 名稱打開資料面板，就可以在 Routines 列表中看到它。
    4. 想更改時間或暫停，同樣直接告訴 bot 即可。
    跟著做

    建立：每日新聞摘要

    你每天早上 8 時（香港時間），請幫我整理 15 至 20 則香港及國際新聞，每則附一句摘要和來源連結，重要的排在前面。

    修改：

    你請把每日新聞改為早上 7 時半發送，星期六和星期日不用發送。

    簡單提醒也可以：

    你平日下午 3 時提醒我喝水和起來走動一下。
    預期結果：bot 確認已建立 routine，資料面板的 Routines 列表會多了一項。第二天早上 8 時左右，你會在對話中收到新聞摘要。

    兩種觸發方式：「定時」（例如每天早上 8 時）和「事件觸發」（例如「有新的 GitHub issue 就通知我」）。後者通常需要先連接服務，也就是下一個階段的內容。

    階段 4

    連接服務（Connector）：連接 GitHub 或 X

    目標：授權 bot 使用你的帳戶讀取外部服務的資料。

    步驟

    1. 直接請 bot 完成一件需要用到某項服務的事，不必自己尋找設定。
    2. 如果尚未連接，bot 會在對話中顯示一張連接卡。
    3. 點擊連接卡，按指示登入並授權你自己的帳戶。
    4. 授權完成後，bot 會繼續完成你原本的要求。
    跟著做

    例子 A：GitHub

    你請幫我查看我在 GitHub 上有哪些 issue 和 pull request 正等待我處理，並列出清單。

    例子 B：X（前稱 Twitter）

    你請幫我搜尋今天 X 上關於香港的熱門貼文，選出討論最多的 10 則，每則用一句話說明重點。
    預期結果：第一次使用時會看到連接卡；授權之後，bot 會列出你在 GitHub 的待辦事項，或 X 熱門貼文的摘要。之後再使用同一項服務便不必再次授權。

    請放心：讀取資料和代你「發出」內容是兩回事。bot 要代你發文、留言或寄出電郵之前，會先擬好草稿讓你查看，經你批准後才會發出。

    階段 5

    儲存技能（Skill）：一句話重用整套做法

    目標：把一個包含多個步驟的任務儲存起來，下次只需說一句話。

    步驟

    1. 先請 bot 完整地做一次任務，過程中發現不對便立即糾正。
    2. （可選）點擊對話頂部的 bot 名稱，資料面板會顯示它的電腦即時畫面；點擊畫面可以全螢幕觀看它如何使用瀏覽器。
    3. 滿意結果之後，請它把這套做法儲存為技能，並取一個容易記的名稱。
    4. 下次直接請它使用這個技能。
    跟著做

    第 1 步：先做一次

    你請幫我比價：Sony WH-1000XM5 耳機目前在香港幾間大型電器店和網店的售價，整理成表格並附上連結，最便宜的排第一。

    第 2 步：儲存為技能

    你請把剛才比價的做法儲存為一個技能，名稱為「比價」。以後我只要說出產品名稱，你就用同樣的方法和格式幫我查詢。

    第 3 步：重用

    你請用「比價」技能查詢 iPad Air。
    預期結果：bot 確認技能已儲存。在第 3 步，它會用同一個表格格式提供 iPad Air 的價格比較。

    Routine 和 Skill 有甚麼分別？Routine 決定「甚麼時候做」（自動觸發）；Skill 決定「怎樣做」（一套做法）。兩者可以一起使用，例如「每個星期一用比價技能查詢 iPad Air」。

    階段 6

    多個 bot 分工合作

    目標：組成一隊 bot，每個專責一項工作，再讓它們互相交接。

    一個 bot 包辦所有事情也可以，但分成幾個會更清晰，每個 bot 的記憶和對話都能專注於自己的工作。例如：

    Bot負責
    Nancy每天早上整理 15–20 則新聞
    Xavier追蹤 X 上的熱門貼文
    Peter比價
    TracyTelegram 橋樑：把訊息轉發到你的 Telegram

    步驟

    1. 再新增一個 bot，按階段 1 的方法把名稱改為「Tracy」，職銜設為「Telegram 橋樑」。
    2. 告訴 Tracy 你想連接 Telegram，然後按畫面指示完成授權（如果有可用的頻道連接器，Tracy 的資料面板還會出現 Channels 一欄）。
    3. 回到 Nancy 的對話，請她完成新聞摘要後交給 Tracy。
    4. 如果想讓幾個 bot 在同一處交流，可以建立一個群組對話，群組的資料面板會列出 Members（成員）。
    跟著做

    對 Nancy 說：

    你 → Nancy每天早上整理好新聞摘要之後，請傳送給 Tracy，請她轉發到我的 Telegram。

    對 Tracy 說：

    你 → TracyNancy 每天早上會傳送新聞摘要給你，你收到後請原文轉發到我的 Telegram，不用修改內容。
    預期結果：第二天早上，Nancy 整理好新聞後會交給 Tracy，你會在 Telegram 收到摘要。首次設定時，bot 可能會先徵求你的確認，才代你發出訊息。

    提示：所有 bot 共用同一部電腦的檔案，所以 A bot 製作的檔案，B bot 也能讀取；但它們的桌面和瀏覽器各自獨立，不會互相干擾。

    階段 7

    小提示與常見問題

    目標：了解如何安全、順暢地長期使用。

    三個好習慣

    1. 說清楚：甚麼時候、做甚麼、需要甚麼格式（例如「列表」、「三點」、「表格」）。
    2. 一個 bot 一項專長：記憶和對話會更清晰。
    3. 先看草稿：凡是代你對外發出的內容，看清楚草稿再批准。

    常見問題

    bot 會不會自行亂發訊息或電郵？

    不會。bot 代你寄出電郵、發送訊息或發文之前，會先擬好草稿讓你查看，經你批准後才發出。不想發出的話，告訴它「不要發」即可。

    如何打開設定（Settings）？

    有三個方法：點擊側邊欄左下角的帳戶按鈕（頭像和帳戶名稱），或按 Cmd+,，或在指令面板中選擇 Open settings。設定包括 General、Computer、Usage & Billing（只限部分帳戶）和 Updates 幾個分頁。

    想切換至深色模式？

    設定 → General → Theme，可選擇 Follow System、Light 或 Dark。

    如何查看 bot 正在做甚麼？

    點擊對話頂部的 bot 名稱（或按 Cmd+Shift+I）打開資料面板，上方會顯示它的電腦即時畫面，點擊即可全螢幕觀看。

    如何刪除一個 bot？

    在側邊欄對該 bot 按滑鼠右鍵，選擇 Delete，然後確認。

    注意：這是永久刪除，對話記錄會一併刪除；沒有封存或隱藏功能，也不是在設定中操作。

    bot 的電腦好像卡住了，怎麼辦？

    先等一會再試，很多時候只是電腦剛剛啟動。如果仍然不行：打開設定，找到 Update Grok Bot's Computer 這一項（屬於電腦修復功能，一般在 Computer 分頁），點擊 Update，再點擊 Click Again to Confirm 確認。

    它會把電腦遷移到一個全新的環境，保留檔案和登入狀態，但之前安裝過的軟件需要重新安裝。下方的 Reset 會還原到上一次的快照，可能會遺失最近的工作，一般不建議使用。

    「更新應用程式」和「更新電腦」有甚麼不同？

    設定 → Updates 中的 Check for Updates 用於更新 Grok Bot 應用程式本身；Update Grok Bot's Computer 則是重建 bot 所用的那部電腦。兩者並不相同。

    找不到教學中提到的某個按鈕？

    部分設定只會在某些帳戶或版本中出現。如果找不到，可以直接問你的 bot：「我想做某件事，應該怎樣操作？」

    跟著做（畢業任務）

    把之前學過的內容結合起來：

    你每個星期五下午 1 時，請用「比價」技能查詢我清單上的產品，整理好後先擬一段訊息讓我查看，經我批准後再交給 Tracy 轉發到 Telegram。
    預期結果：bot 建立一個 routine（可能會出現確認卡），每個星期五依照執行，並在發出之前先讓你查看草稿。

    🎉 完成全部 8 個階段後，你已經掌握 Grok Bot 的主要功能。之後有任何想做的事，都可以直接問你的 bot。
